# BEABÁ
## :open_book: Sobre o projeto
O BEABÁ nasceu no Centro de Informática da Universidade Federal de Pernambuco, como um projeto da disciplina de Concepção de Artefatos Digitais. Nosso objetivo é oferecer uma ferramenta que ajude pessoas idosas analfabetas no processo de letramento. Este projeto está em fase inicial de desenvolvimento.
